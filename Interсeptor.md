# Какие первоочередные цели?

1. БПЛА разведчики самолетного типа
2. Тяжелые БПЛА коптерного типа ("Баба Яга") 
3. БПЛА ретрансляторы или наблюдатели коптерного типа
  
# Какие есть способы поражения целей?
1. Воздушный таран - предполагает столкновение с целью и гибель перехватчика
2. Огневое поражение - предполагает оказание огневое поражения цели (с помощью дроби, сети и т.д.), не предполагает столкновения с целью и гибель перехватчика, позволяет многоразовое использование перехватчика
3. Воздушный подпор - слишком сложно и ненадежно

# Как может выглядеть перехватчик?

1. Быстрый БПЛА с FPV управлением, способный летать быстрее, чем потенциальная цель
2. Средства огневого поражения цели, устанавливаемые на перехватчике
3. Отдельный программно-аппаратный комплекс, устанавливаемый на перехватчик, интегрированный с системой управления перехватчика и средствами огневого поражения. Программно-аппаратный комплекс
- получает видео от FPV камеры перехватчика
- анализирует его с реальном времени на предмет наличия цели
- при наличии цели определяет его положение относительно перехватчика 
- выдает команды управления, которые позволяют перехватчику сближаться с целью 
- определяет расстояние до цели с помощью лазерного дальномера
- при сближении с целью на требуемую дистанцию, выдает команды управления на применение средств огневого поражения

__Для сокращения затрат (в том числе на отдельный программно-аппаратный комплекс) перехватчик должен быть многоразовым.__

# Как может выглядеть использование перехватчика?

1. Оператор, получив информацию о наличии цели в воздухе, запускает перехватчик и доводит его до цели в ручном режиме до включения режима "захвата"
2. После "захвата" перехватчик самостоятельно отслеживает цель, сближается с ней и наносит ей огневое воздействие
3. После нанесения огневого воздействия, перехватчик возвращается на базу в автоматическом или ручном режиме

1. Задача обнаружения цели (БПЛА противника) по видео может быть решена с помощью обученной нейронной сети - __ТАКАЯ СЕТЬ УЖЕ ЕСТЬ__
2. Для работы нейронной сети нужен достаточно мощный вычислитель - например, ....
3. При использовании дроби расстояние до цели должно быть не более 30-40 метров, поэтому желательно использовать лазерный дальномер для определения точного расстояния до цели
4. Программно-аппаратный комплекс должен получать видео с видеокамеры перехватчика и выдавать команды в тракт управления БПЛА аналогично командам с пульта оператора.
5. Аналогично функционалу активации сбросов, должен быть реализован функционал активации средств огневого поражения. 

# Какие нужно решить первоочередные задачи?
1. Найти или разработать средства огневого поражения устанавливаемые на БПЛА
2. Найти или разработать подходящий для роли перехватчика БПЛА
3. Выбрать подходящую по вычислительной мощности и форм-фактору аппаратную платформу, на которой сможет работать имеющаяся обученная нейронная сеть
4. Реализовать программно-аппаратную интеграцию полетного контроллера БПЛА, его камер, дальномера, вычислителя, на котором будет работать нейронная сеть и средств огневого поражения
